Del promedio al contraste

Cuando sigma es conocida:

Z = (X̄ - mu) / (sigma / sqrt(n))

Cuando sigma es desconocida:

T = (X̄ - mu) / (s / sqrt(n))

La t de Student tiene colas más pesadas cuando n es pequeño porque también estamos estimando la dispersión.

Checklist Conceptual

  • Muestra: un vector aleatorio con n mediciones independientes e idénticamente distribuidas.
  • Estadístico: una función que convierte la muestra en un número.
  • Estimador: un estadístico usado para aproximar un parámetro desconocido.
  • TLC: explica por qué el promedio se vuelve aproximadamente normal aunque la población original no lo sea.
  • Intervalo: combina estimación puntual, error estándar y valor crítico.
